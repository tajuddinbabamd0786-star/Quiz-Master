🎓 QuizTrack – Classroom Quiz Management System
A Java-based Smart Classroom Quiz Management System that allows teachers to create quizzes, manage student records, record marks, automatically calculate Pass/Fail results, and analyze student performance using highest, lowest, and average marks.

Features

- Create quizzes with maximum and pass marks.
- Add and manage student records.
- Record marks for each quiz.
- Automatically calculate PASS/FAIL results.
- Display highest, lowest, and average marks.

Technologies Used

- Java
- OOP Concepts
- Arrays

Purpose

To simplify quiz management and make student performance evaluation easy and efficient.
